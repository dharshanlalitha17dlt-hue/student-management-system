# Student Management System

## About the Project
This is a simple Student Management System developed using the C programming language.

It helps users manage student records through a menu-driven program.

## Features
- Add Student Records
- Display All Students
- Search Students Using ID
- Calculate Average Marks
- Check Duplicate Student IDs

## Concepts Used
- Structures
- Arrays
- Functions
- Loops
- Conditional Statements
- Switch Case

## Language Used
C Programming
