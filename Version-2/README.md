# Student Management System – Version 2

## About the Project
This is an improved version of the Student Management System developed using the C programming language. It helps users manage student records through a simple menu-driven program.

## Features
- Add new student records
- Display all student details
- Search for a student using ID
- Calculate average marks
- Update student marks
- Delete student records
- Count total students
- Check for duplicate student IDs
- Validate marks between 0 and 100

## Concepts Used
- Structures (`struct`)
- Arrays
- Functions
- Loops (`do-while`)
- Conditional statements (`switch`)
- Pointers
- Input validation

## How to Run

Compile the program:

```bash
gcc main.c -o main
```

Run the program:

```bash
./main
```

For Windows PowerShell:

```powershell
.\main.exe
```

## What's New in Version 2?
Compared to Version 1, this version includes:
- Updating student marks
- Deleting student records
- Checking duplicate IDs
- Validating marks
- Counting total students

## Note
Student records are stored temporarily in memory. The data will be lost when the program is closed.
